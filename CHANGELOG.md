# Changelog

## 1.0.0 — 2026-10-13

Initial English-edition release, based on the shared workbench implementation.

- English controls, player labels, documentation, and messages.
- Random seed 1 as the initial default.
- Six upstream atommovr single-species algorithms, four target patterns, and manual initial occupancy.
- Active-tweezer capacity limits, complete crossed-AOD intersections, and conservative trajectory scheduling.
- Atom lifetime, pickup and putdown success rates, and pickup, putdown, acceleration, and deceleration durations.
- Single-case algorithm comparisons, repeated trials, and JSON/CSV exports.
- Playback, pause, replay, step, seek, and 0.25×–4× presentation speed.
- Launch entry points for Windows, Linux, and macOS using a shared setup program.
- A reference upstream revision and explicit attribution separating workbench contributions from upstream algorithms and models.

See [VALIDATION.md](VALIDATION.md) for tested behavior, platforms, and model limitations. Versions identify this English-edition repository; the upstream atommovr version is separate.
